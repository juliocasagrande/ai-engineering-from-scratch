# Fase 6: Discurso e áudio

> A outra metade da comunicação humana, ouvir, entender, falar.

## Comece esta fase no GitHub

**Prerequisites:** Phase 1 vectors, matrices, and probability. The first demo
utiliza apenas a biblioteca padrão Python.

**First lesson:** [Audio Fundamentals](01-audio-fundamentals/)

Execute este comando a partir da raiz do repositório:

```bash
python3 phases/06-speech-and-audio/01-audio-fundamentals/code/main.py
```

Mantenha o comando, código de saída, picos de frequência detectados, freqüência alias, e um
Explicação do motivo pelo qual um filtro de baixa passagem deve ser executado antes da descida da amostra.
