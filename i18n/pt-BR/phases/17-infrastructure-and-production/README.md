## Comece esta fase no GitHub

**Prerequisites:** Phase 11 LLM Engineering and Phase 13 Tools and Protocols.

**First lesson:** [Managed LLM Platforms](01-managed-llm-platforms/)

Execute este comando a partir da raiz do repositório:

```bash
python3 phases/17-infrastructure-and-production/01-managed-llm-platforms/code/main.py
```

Mantém o comando, código de saída, comparação de custos e latência, aumento da redundância,
e um breve registro de decisão que nomeia as suposições de carga de trabalho por trás da sua escolha.
