# Fase 4: Visão por Computador

> De pixels para compreensão através de imagem, vídeo e 3D.

## Comece esta fase no GitHub

**Prerequisites:** Phase 1 Lesson 12, Tensor Operations, and Phase 3 Lesson 11,
A primeira demonstração precisa apenas do NumPy.

**First lesson:** [Image Fundamentals](01-image-fundamentals/)

Execute este comando a partir da raiz do repositório:

```bash
python3 phases/04-computer-vision/01-image-fundamentals/code/main.py
```

Mantenha o comando, o código de saída, as formas HWC e CHW, as estatísticas normalizadas do canal,
A diferença de píxeles de ida e volta e a rugosidade da interpolação.
Imagem sintética determinista e não utiliza a rede.
