# Fase 8: IA Gerativa

> Criar imagens, vídeo, áudio, 3D, e muito mais.

## Comece esta fase no GitHub

**Prerequisites:** Phase 2 ML Fundamentals, Phase 3 Deep Learning Core, and
Fase 7 Lição 14, Construir um Transformador a partir do zero.

**First lesson:** [Generative Model Taxonomy and History](01-generative-models-taxonomy-history/)

Execute este comando a partir da raiz do repositório:

```bash
python3 phases/08-generative-ai/01-generative-models-taxonomy-history/code/main.py
```

Mantenha o comando, código de saída, estimativas de densidade, amostras geradas e um
frase explicando o que um gerador implícito não pode responder sobre `p(x)`- Não .

**Next action:** Mudança a semente aleatória, compara as estimativas de densidade, então
Continuar [Autoencoders and VAE](02-autoencoders-vae/)- Não .

Explore o [full Phase 8 lesson list](../../README.md#phase-8) ou o
[cross-phase roadmap](../../ROADMAP.md)- Não .

A formação de um grupo de professores de ensino superior é uma das principais prioridades da formação profissional.
Uma demonstração Python executável, um diagrama e uma habilidade nomeada para o seu agente.
