# Fase 9: Aprendizagem reforçada

## Comece esta fase no GitHub

**Prerequisites:** Phase 1 probability and distributions, plus Phase 2 Lesson
01 para a taxonomia ML.

**First lesson:** [MDPs, States, Actions and Rewards](01-mdps-states-actions-rewards/)

Execute este comando a partir da raiz do repositório:

```bash
python3 phases/09-reinforcement-learning/01-mdps-states-actions-rewards/code/main.py
```

Mantenha o comando, o código de saída, retornos aleatórios e gananciosos, grades de valor, e um
Sentença que liga a qualidade da política à devolução esperada.
