# Fase 1: Fundamentos matemáticos

> A intuição por trás de todos os algoritmos de IA, através de código, não de livros didáticos.

## Comece esta fase no GitHub

**Prerequisites:** Complete Phase 0, or confirm that Python 3.11+ and Git work
da raiz do repositório.

**First lesson:** [Linear Algebra Intuition](01-linear-algebra-intuition/)

Execute este comando a partir da raiz do repositório:

```bash
python3 phases/01-math-foundations/01-linear-algebra-intuition/code/vectors.py
```

Mantenha o comando, código de saída, saída de vetor normalizado, projeção residual,
e uma frase explicando por que um produto de vetor de matriz é uma rede neural
- E o que é?
