# Fase 10: LLM do zero

> Construir, treinar e compreender modelos de linguagem grandes.

## Comece esta fase no GitHub

**Prerequisites:** Phase 5 NLP Foundations. Phase 7 Transformers is strongly
Recomendado antes das aulas de construção de modelos.

**First lesson:** [Tokenizers](01-tokenizers/)

Execute este comando a partir da raiz do repositório:

```bash
python3 phases/10-llms-from-scratch/01-tokenizers/code/main.py
```

Mantenha o comando, código de saída, codificar/decodificar resultados de ida e volta, aprendi a fundir
Contagem e proporções de compressão. `tiktoken` É uma comparação opcional.

**Next action:** Adicione uma palavra que o pequeno corpus não tenha visto, inspecione as peças,
Depois continua [Building a Tokenizer from Scratch](02-building-a-tokenizer/)- Não .
