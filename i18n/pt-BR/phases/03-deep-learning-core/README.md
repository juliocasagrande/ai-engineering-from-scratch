# Fase 3: Profundo de Aprendizagem Profunda

> Redes neurais desde os primeiros princípios, sem estruturas até que você construa uma.

## Comece esta fase no GitHub

**Prerequisites:** Phase 1 Linear Algebra Intuition. Phase 2 is recommended
para o vocabulário de avaliação de modelos.

**First lesson:** [The Perceptron](01-the-perceptron/)

Execute este comando a partir da raiz do repositório:

```bash
python3 phases/03-deep-learning-core/01-the-perceptron/code/perceptron.py
```

Mantenha o comando, código de saída, resultados de entrada convergentes, falha XOR de um único
Perceptron, e as últimas previsões de dois camados de XOR.
