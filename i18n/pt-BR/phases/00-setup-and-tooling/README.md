# Fase 0: Configuração e ferramentas

> Prepare seu ambiente para tudo o que vem a seguir.

## Comece esta fase no GitHub

**Pré-requisitos:** Nenhum. Para começar, você precisa do Git e do Python 3.11 ou mais recente. As outras ferramentas serão instaladas apenas quando o percurso escolhido exigir.

**Primeira aula:** [Ambiente de desenvolvimento](01-dev-environment/)

Na raiz do repositório, execute a verificação inicial correspondente ao seu percurso:

```bash
python3 phases/00-setup-and-tooling/01-dev-environment/code/verify.py --route beginner
```

Guarde o comando, a pasta de trabalho (raiz do repositório), o código de saída, os resultados das verificações obrigatórias e o comando `Next:` exibido. A ausência de uma ferramenta opcional não é uma falha.

**Próxima ação:** Corrija cada falha obrigatória e execute novamente até que o comando termine com código 0. Depois, continue para [Git e colaboração](02-git-and-collaboration/).

Consulte a [lista completa de aulas da fase 0](../../README.md#phase-0) ou o [roteiro das fases](../../../../ROADMAP.md).
